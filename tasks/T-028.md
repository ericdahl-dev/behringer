## Goal

Extract a new `cli/osc_io.{h,c}` module that owns all OSC socket I/O, the
XR18 `/xinfo` handshake, and blob offset parsing. Today the 4-byte OSC
alignment formula (`((strlen+1+3)&~3)`) appears **7 times** verbatim in
`XAir_ToastSaver.c`, the xinfo handshake appears **twice**, and
`osc_query_float` / `osc_query_int` are near-identical twins. Moving these
into a single module gives them one home, makes every call site shorter, and
makes `run_doctor`, `run_ringout`, and `handle_meters4` independently testable
without a mixer.

This is architecture candidate #1 from the 2026-06-29 review.

## What to build

### `cli/osc_io.h` — new public interface

```c
#ifndef OSC_IO_H
#define OSC_IO_H

#include <stdint.h>
#include <netinet/in.h>

typedef struct {
    int                fd;
    struct sockaddr_in xip;
    struct sockaddr   *xip_addr;
    socklen_t          xip_len;
} OscConn;

/* Lifecycle */
int  osc_conn_init(OscConn *c, const char *ip, int port);
void osc_conn_close(OscConn *c);

/* /xinfo handshake — returns 0 on success, -1 on timeout/mismatch */
int osc_handshake(OscConn *c);

/* Fire-and-forget sends */
void osc_send_no_args(OscConn *c, const char *path);
void osc_send_int(OscConn *c, const char *path, int val);
void osc_send_float(OscConn *c, const char *path, float val);
void osc_send_int_float(OscConn *c, const char *path, int ival, float fval);

/* Request-reply queries — return 0 and set *out, or -1 on timeout/error */
int osc_query_int(OscConn *c, const char *path, int *out);
int osc_query_float(OscConn *c, const char *path, float *out);

/* Locate the blob payload in a received /meters/4 packet.
 * buf/buflen: raw UDP bytes.
 * Returns pointer to first blob byte and sets *blob_len, or NULL on error. */
const uint8_t *osc_locate_blob(const char *buf, int buflen, int *blob_len);

#endif
```

### `cli/osc_io.c` — implementation

- `osc_conn_init`: fill `OscConn`, create UDP socket, set `xip_addr` and
  `xip_len`. Returns 0 or -1 on `socket()` error.
- `osc_handshake`: send `/xinfo`, wait 1 s, verify reply starts with `/xinfo`.
  Called by `run_doctor` and the reactive startup path.
- Sends: thin wrappers around `Xsprint` (keep `extern int Xsprint(...)` in
  `osc_io.c`; remove it from `XAir_ToastSaver.c`).
- `osc_query_int` / `osc_query_float`: merge the two existing near-identical
  functions. The only difference is the final cast; share a common `osc_query_raw`
  helper or accept a `char type` argument internally.
- `osc_locate_blob`: the repeated 3-line formula:
  ```c
  int ap = ((int)strlen(buf) + 1 + 3) & ~3;
  int tp = ((int)strlen(buf + ap) + 1 + 3) & ~3;
  return (blob_start < buflen) ? (uint8_t*)buf + ap + tp : NULL;
  ```
  Returns `NULL` if `ap + tp >= buflen`.

### Migration in `XAir_ToastSaver.c`

1. Add `#include "osc_io.h"` and `OscConn conn;` to `AppState`.
2. Replace the four socket fields (`fd`, `xip`, `xip_addr`, `xip_len`) with the
   `OscConn` field. Update all direct `s->fd`, `s->xip_addr` references to go
   through `s->conn`.
3. Replace all 7 inline blob-offset computations with `osc_locate_blob()`. The
   call sites are:
   - `osc_query_float` (line ~189)
   - `osc_query_int` (line ~213)
   - `run_ringout` baseline loop (~702)
   - `run_ringout` control loop (~746)
   - `handle_meters4` (~920 in main loop)
   - `main` loop (~1120)
   - any others grep reveals: `grep -n "addr_padded" cli/XAir_ToastSaver.c`
4. Replace the two xinfo handshake blocks with `osc_handshake(&s->conn)` — one
   in `main()` and one in `run_doctor()`.
5. Remove the four now-redundant static helpers (`osc_send_raw`, `osc_no_args`,
   `osc_int`, `osc_float`, `osc_int_float`) and the `extern int Xsprint` declaration
   from `XAir_ToastSaver.c`; replace call sites with the `osc_send_*` equivalents.
6. Remove the local `osc_query_float` and `osc_query_int` static functions and
   replace call sites with the `osc_io` versions.

Add `osc_io.c` to the `XAir_ToastSaver` link line in `cli/Makefile`. Confirm

## Acceptance Criteria

- [ ] `cli/osc_io.h` and `cli/osc_io.c` exist with the interface above.
- [ ] `XAir_ToastSaver.c` has zero inline blob-offset computations — every call
      goes through `osc_locate_blob()`.
- [ ] `XAir_ToastSaver.c` has one `/xinfo` handshake path — `osc_handshake()`.
- [ ] `osc_query_float` and `osc_query_int` are no longer static functions in
      `XAir_ToastSaver.c`; the `osc_io.h` versions are used instead.
- [ ] `make XAir_ToastSaver` compiles clean, zero warnings.
- [ ] `make check` still passes (all existing test suites green).
- [ ] `cli/test_osc_io.c` with at least these cases:
      - `osc_locate_blob` returns `NULL` on a buffer that's too short.
      - `osc_locate_blob` returns the correct offset for a synthetic `/meters/4`
        packet (build one by hand with known lengths).
      - `osc_handshake` can be driven with a loopback socket (or skip if a mock
        socket is out of scope — at minimum the parse helpers are tested).
