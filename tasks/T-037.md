## Goal

Move the log ring buffer (6 file-statics + `log_push`) out of
`XAir_ToastSaver.c` into a new `cli/log.c` / `cli/log.h` module. This makes
the log testable and removes global state from the main file.

## Current state

In `cli/XAir_ToastSaver.c` (~lines 112–131):

```c
#define LOG_CAP  200
#define LOG_LINE 128
static char        g_log[LOG_CAP][LOG_LINE];
static const char *g_log_ptrs[LOG_CAP];
static int         g_log_head   = 0;
static int         g_log_count  = 0;
static int         g_log_scroll = 0;

static void log_push(const char *fmt, ...) {
    va_list ap;
    va_start(ap, fmt);
    vsnprintf(g_log[g_log_head], LOG_LINE, fmt, ap);
    va_end(ap);
    g_log[g_log_head][LOG_LINE - 1] = '\0';
    g_log_head = (g_log_head + 1) % LOG_CAP;
    if (g_log_count < LOG_CAP) g_log_count++;
    if (g_log_scroll > 0) g_log_scroll++;
    for (int i = 0; i < g_log_count; i++)
        g_log_ptrs[i] = g_log[(g_log_head - g_log_count + i + LOG_CAP) % LOG_CAP];
}
```

`g_log_ptrs`, `g_log_count`, `g_log_scroll` are used in TUI draw calls
throughout the file, e.g.:
```c
tui_draw_reactive(&ctx, (const char * const *)g_log_ptrs, g_log_count, g_log_scroll);
```

## Target state

### `cli/log.h`

```c
#ifndef LOG_H
#define LOG_H

#define LOG_CAP  200
#define LOG_LINE 128

void        log_push(const char *fmt, ...);
void        log_scroll_down(void);    /* g_log_scroll++ */
void        log_scroll_reset(void);   /* g_log_scroll = 0 */
int         log_count(void);          /* g_log_count */
int         log_scroll(void);         /* g_log_scroll */
const char *const *log_lines(void);   /* g_log_ptrs (snapshot valid until next push) */

#endif
```

### `cli/log.c`

Move the 6 statics and `log_push` here. Add the accessor functions above.

### `cli/XAir_ToastSaver.c`

- Remove the 6 statics and `log_push` definition.
- Add `#include "log.h"`.
- Replace all direct references:
  - `g_log_ptrs` → `log_lines()`
  - `g_log_count` → `log_count()`
  - `g_log_scroll` → `log_scroll()`
  - `g_log_scroll++` / `g_log_scroll = 0` → `log_scroll_down()` / `log_scroll_reset()`
    (these appear in `tui_poll_key` call sites and the "keep relative position" scroll logic)

### `cli/Makefile`

Add `log.c` to the `XAir_ToastSaver` link line:
```makefile
XAir_ToastSaver: X32lib
	$(CC) $(CFLAGS) -o $(BUILD)/$@ $@.c log.c toast_logic.c ringout_logic.c \
	    ringout_profile.c mic_cal.c rta_bins.c osc_io.c tui.c $(LDFLAGS) -lncursesw
```

## Acceptance criteria

- [ ] `make check` passes
- [ ] `make test-ringout-emu` passes
- [ ] `cli/log.h` and `cli/log.c` exist
- [ ] `XAir_ToastSaver.c` contains no definition of `log_push` or `g_log*`
- [ ] All `g_log_scroll` mutations go through `log_scroll_down()` /

      remain)
- [ ] No behaviour change

## Notes

- `g_log_scroll` is read and written in the `tui_poll_key` callbacks inside
  `run_ringout` and `run_reactive`. The write path (`g_log_scroll++`) maps to
  `log_scroll_down()`. The reset (`g_log_scroll = 0`) can be handled in
  `log_push` internally (the current logic already does `if (g_log_scroll > 0)
  g_log_scroll++` — keep this behaviour inside `log.c`).
- The accessors (`log_count`, `log_scroll`, `log_lines`) are intentionally
  simple getters — no locking needed (single-threaded).
- Do not add a test binary for `log.c` in this task — the existing integration
  path (emulator) is sufficient. A dedicated `test_log.c` can be added later.
- Prefer editing `Makefile` in-place rather than creating a new build system.
