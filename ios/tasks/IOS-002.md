## Goal

Implement `ToastSaverCore` — a pure Swift port of `src/toast_logic.c`. No Apple framework imports. Builds and tests on Linux with `swift test`. This is the algorithmic heart of the app; the iOS layer (IOS-003 through IOS-006) calls into this package.

## Public interface

### GEQMap.swift

```swift
public enum GEQMap {
    /// RTA bin index for each GEQ par (index 0 = par 01).
    /// Calibrated: 1 kHz tone → bin 56 of a 100-bin RTA.
    public static let bins: [Int] = [
         0,  3,  7, 10, 13, 16, 20, 23, 26, 30,
        33, 36, 39, 43, 46, 49, 53, 56, 59, 63,
        66, 69, 72, 76, 79, 82, 86, 89, 92, 96,
        99
    ]

    /// Map an RTA bin index (0–99) to the nearest GEQ par number (1–31).
    public static func par(forBin bin: Int) -> Int
}
```

### NarrownessFilter.swift

```swift
public enum NarrownessFilter {
    /// Returns true if bins[peak] is at least minDb above the average of
    /// neighbor bins sampled skip..skip+span positions away on each side.
    /// Requires at least one sample on each side; returns false otherwise.
    public static func isNarrow(
        bins: [Float],
        peak: Int,
        skip: Int = 2,
        span: Int = 3,
        minDb: Float = 10.0
    ) -> Bool
}
```

### BaselineTracker.swift

```swift
public enum BaselineTracker {
    /// Exponential smoothing: baseline[i] = (1-alpha)*baseline[i] + alpha*bins[i]

        baseline: inout [Float],
        bins: [Float],
        alpha: Float = 0.005
```

### FeedbackDetector.swift

```swift
/// Stateful detector: tracks confirm counters and baseline per instance.
public final class FeedbackDetector {
    public let binCount: Int
    public let threshold: Float      // dB above baseline to trigger
    public let confirmFrames: Int    // consecutive narrow-peak frames before notching
    public let narrowSkip: Int
    public let narrowSpan: Int
    public let narrowMinDb: Float

    public init(
        binCount: Int = 100,
        threshold: Float = 20.0,
        confirmFrames: Int = 3,
        narrowSkip: Int = 2,
        narrowSpan: Int = 3,
        narrowMinDb: Float = 10.0
    )

    /// Process one RTA frame. Returns the GEQ par (1–31) to notch, or nil.
    /// Already-notched pars must be excluded by the caller (pass notchedPars).
    public func process(
        bins: [Float],
        baseline: [Float],
        notchedPars: Set<Int> = []
    ) -> Int?

    /// Reset all confirmation counters (call when no peak or after notch fires).
    public func resetConfirm()
}
```

## OSC packet layout

Replicate `Xsprint` from `src/X32lib/Xsprint.c` in Swift:

- Address string: null-terminated, padded to 4-byte boundary
- Type tag string: null-terminated, padded to 4-byte boundary  
- Float32: big-endian (use `withUnsafeBytes` + `.bigEndian` bit pattern)

```swift
// Helper — pads data to next 4-byte boundary with null bytes
private static func padded(_ s: String) -> Data {
    var d = Data(s.utf8) + Data([0])
    while d.count % 4 != 0 { d.append(0) }
    return d
}
```

For `/fx/4/par/18 ,f 0.5`:
```
2f 66 78 2f  34 2f 70 61  72 2f 31 38  00 00 00 00   /fx/4/par/18....
2c 66 00 00                                            ,f..
3f 00 00 00                                            0.5 as big-endian float32
```

## FeedbackDetector.process() algorithm

```swift
public func process(bins: [Float], baseline: [Float], notchedPars: Set<Int> = []) -> Int? {
    // 1. Find highest bin that exceeds baseline + threshold (strict >)
    guard let peakBin = detectPeak(bins: bins, baseline: baseline) else {
        resetConfirm(); return nil
    }
    // 2. Narrowness gate
    guard NarrownessFilter.isNarrow(bins: bins, peak: peakBin,
                                     skip: narrowSkip, span: narrowSpan,
                                     minDb: narrowMinDb) else {
        resetConfirm(); return nil
    }
    // 3. Accumulate confirmation; reset all other pars
    let par = GEQMap.par(forBin: peakBin)
    for i in 0..<confirmCounters.count {
        confirmCounters[i] = (i == par - 1) ? confirmCounters[i] + 1 : 0
    }
    // 4. Already notched — don't fire again
    if notchedPars.contains(par) { return nil }
    // 5. Not confirmed yet
    if confirmCounters[par - 1] < confirmFrames { return nil }
    // 6. Fire
    confirmCounters[par - 1] = 0
    return par
}
```

## Notes

- `confirmCounters` is a private `[Int]` of length 31 on the `FeedbackDetector` instance.
- `detectPeak` is a private helper method; it is not part of the public API.
- The GEQ bin table is the same 31 values as `TOAST_GEQ_BIN` in `cli/toast_logic.c` — do not guess or recompute them.
