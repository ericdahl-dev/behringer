## Goal

Prepare a repeatable local build environment for compiling the X32-Behringer apps on this OS.

## Acceptance Criteria

- [x] Required compiler and build tools are installed or documented as prerequisites.
- [x] Required native development libraries are installed or documented as prerequisites.
- [x] A local build directory convention is chosen and documented.
- [x] Build commands can be rerun from a clean checkout without relying on IDE-only state.
- [x] Any OS-specific compiler flags, include paths, or linker flags are centralized in one documented place.
- [x] A smoke command exists to confirm the toolchain can compile and link a trivial C program.

## Notes

Prefer a command-line build path suitable for automation. If upstream assumes Eclipse or MinGW for some programs, capture the equivalent command-line assumptions before changing code.
