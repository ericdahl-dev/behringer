## Goal

Create `src/XAir_ToastSaver.c` — the entry point and connection scaffold for the Toast Saver tool. This is a new standalone C tool alongside `XAir_Command.c`, `XAir.c`, etc. It connects to an XR18 over UDP/OSC, configures the RTA source, and holds the main loop structure for the feedback detector (later tasks implement detection, display, and notching).

## Context

The XR18 communicates over UDP port **10024** using Open Sound Control (OSC). All existing tools in `src/` follow this same pattern. The closest reference is `src/XAir_Command.c`, which shows the socket setup, handshake, `/xremote` keepalive, and receive loop. Key library functions are in `src/X32lib/`: `Xsprint()` for building OSC messages, `Xcparse()` for parsing them.

XAir (not X32) uses port 10024 and the `/xinfo` handshake (sends `/xinfo`, waits for the reply). Do NOT use `X32Connect()` from X32lib — it connects to port 10023 and sends `/info`, which is wrong for XAir. Roll the socket setup directly in this file, following `XAir_Command.c`.

## Acceptance Criteria

- [ ] `src/XAir_ToastSaver.c` exists and compiles cleanly with `gcc -O0 -g3 -Wall -IX32lib XAir_ToastSaver.c -LX32lib -lX32 -lm`.
- [ ] Accepted args via `getopt`:
  - `-i <ip>` — XR18 IP address (required; exit with usage if missing)
  - `-c <channel>` — RTA source channel 1–18 (default: 1)
  - `-s <slot>` — FX slot containing the TEQ, 1–4 (default: 4)
  - `-t <threshold>` — spike detection threshold in dB above noise floor (default: 20.0)
  - `-d <cut>` — notch depth in dB, negative (default: -6.0)
  - `-r <release>` — seconds before a notch is released (default: 10.0)
  - `-v` — verbose: print raw OSC traffic
- [ ] UDP socket created on port 10024. `/xinfo` sent on startup; reply awaited with a 1-second timeout. If no reply, print error and exit.
- [ ] `/xremote` sent immediately after handshake and then every **9 seconds** via a `gettimeofday`-based timer (not a blocking sleep — the main loop must stay responsive to incoming meter packets).
- [ ] RTA source configured: send `/-stat/rta/source ,i {channel}` after handshake. Set RTA detection mode to PEAK and decay to 0.25: `/-prefs/rta ,if 0 0.25`.
- [ ] RTA subscription sent: `/meters ,siii /meters/4 0 0 0`.
- [ ] Main loop: `select()` with 60 ms timeout, reads incoming UDP packets into a receive buffer (512 bytes min). Dispatches `/meters/4` blobs to a stub function `handle_meters4(uint8_t *blob, int len)` (stub may be empty for this task).
- [ ] Graceful shutdown on `SIGINT` (Ctrl-C): restore all notched TEQ bands to flat (0.5) before exit. The band state array can be a stub for this task — the restore loop just needs to exist.
- [ ] `main()` prints startup summary: IP, channel, FX slot, threshold, cut depth, release time.

## OSC Message Building

Use `Xsprint()` from `X32lib/Xsprint.c`:

```c
extern int Xsprint(char *bd, int index, char format, void *bs);
```

- `format 's'` — OSC string (address or string arg)
- `format 'i'` — int32 arg
- `format 'f'` — float32 arg
- `format 'T'` — type tag string (pass the tag string as `void *`)

Example — send `/xinfo`:
```c
char buf[512];
int len = Xsprint(buf, 0, 's', "/xinfo");
sendto(Xfd, buf, len, 0, ...);
```

Example — send `/-stat/rta/source ,i 1`:
```c
int ch = 1;
int len = 0;
len = Xsprint(buf, len, 's', "/-stat/rta/source");
len = Xsprint(buf, len, 'T', ",i");
len = Xsprint(buf, len, 'i', &ch);
sendto(Xfd, buf, len, 0, ...);
```

## Notes

- XAir port is 10024, not 10023. Hard-code it — do not use `X32Connect()`.
- Keep all globals in a single `AppState` struct at the top of the file so later tasks can extend it cleanly.
- The `handle_meters4()` stub signature should be: `static void handle_meters4(const uint8_t *blob, int blen, AppState *s)`.
- Do not add ncurses or any external dep beyond `-lm` for this task.
