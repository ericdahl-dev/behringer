## Goal

Split `handle_meters4()` (cognitive complexity 48, lines 79) into three
functions — a dispatcher and two phase handlers — so that the baseline
calibration phase and the steady-state detection phase are independently
readable and testable.

## Current state

`handle_meters4()` in `cli/XAir_ToastSaver.c` (docstring says
"// ── /meters/4 blob handler"):

```c
static void handle_meters4(const uint8_t *blob, int blen, AppState *s) {
    if (parse_meters4_blob(blob, blen, s->bins) != 0) return;
    for (int i = 0; i < RTA_BIN_COUNT; i++) s->bins[i] += s->mic_corr[i];

    /* baseline calibration */
    if (!s->baseline_ready) {
        for (int i = 0; i < 100; i++) s->baseline_accum[i] += s->bins[i];
        s->baseline_count++;
        if (s->baseline_count >= BASELINE_FRAMES) {
            /* compute baseline, set s->baseline_ready = 1, log, draw */
        }
        if (!s->verbose) { /* TUI draw */ }
        return;
    }

    /* exponential baseline update */
    update_baseline(s->baseline, s->bins, 100, 0.005f);

    if (s->verbose) { /* verbose peak log */ }

    /* toast_step() dispatch loop */
    ToastAction acts[32];
    int nacts = toast_step(&s->toast, s->bins, s->baseline, acts, 32);
    for (int i = 0; i < nacts; i++) {
        /* handle NOTCH / RELEASE_RAMP / RELEASE_DONE */
    }
    if (!s->verbose) { /* TUI draw */ }
}
```

## Target state

Rename the outer function to `handle_meters` (it now works for both XR18 and
X32 paths after T-033). Split into three:

```c
/* Phase 1: accumulate until BASELINE_FRAMES, then lock in the baseline. */
static void handle_calibration_frame(AppState *s) {
    for (int i = 0; i < 100; i++) s->baseline_accum[i] += s->bins[i];
    s->baseline_count++;
    if (s->baseline_count >= BASELINE_FRAMES) {
        for (int i = 0; i < 100; i++)
            s->baseline[i] = s->baseline_accum[i] / BASELINE_FRAMES;
        s->baseline_ready = 1;
        float sum = 0.0f;
        for (int i = 0; i < 100; i++) sum += s->baseline[i];
        char msg[128];
        snprintf(msg, sizeof(msg),
                 "[baseline] established: avg noise floor = %.1f dBFS", sum / 100.0f);
        log_push("%s", msg);
        if (s->verbose) printf("%s\n", msg);
    }
    if (!s->verbose) {
        TuiReactiveCtx ctx = make_reactive_ctx(s);
        tui_draw_reactive(&ctx, log_lines(), log_count(), log_scroll());
    }
}

/* Phase 2: steady-state detection — update baseline, run toast_step, draw. */
static void handle_detection_frame(AppState *s) {
    update_baseline(s->baseline, s->bins, 100, 0.005f);
    if (s->verbose) { /* peak log */ }
    ToastAction acts[32];
    int nacts = toast_step(&s->toast, s->bins, s->baseline, acts, 32);
    for (int i = 0; i < nacts; i++) { /* NOTCH / RELEASE_RAMP / RELEASE_DONE */ }
    if (!s->verbose) {
        TuiReactiveCtx ctx = make_reactive_ctx(s);
        tui_draw_reactive(&ctx, log_lines(), log_count(), log_scroll());
    }
}

/* Dispatcher: parse the blob, apply mic correction, route to phase. */
static void handle_meters(const uint8_t *blob, int blen, AppState *s) {
    if (parse_meters4_blob(blob, blen, s->bins) != 0) return;
    for (int i = 0; i < RTA_BIN_COUNT; i++) s->bins[i] += s->mic_corr[i];
    if (!s->baseline_ready)
        handle_calibration_frame(s);
    else
        handle_detection_frame(s);
}
```

Update the two call sites in `run_reactive()` and `run_ringout()` baseline loop
that currently call `handle_meters4(blob, blen, &s)` to call `handle_meters(...)`.

Also rename the section comment from `/* ── /meters/4 blob handler */` to
`/* ── meters blob handler */`.

## Notes

- If T-035 (AppConfig/AppRuntime split) has landed, the signatures become
  `handle_calibration_frame(const AppConfig*, AppRuntime*)` etc. Update
  accordingly.
- If T-037 (log.c) has landed, `log_push`, `log_lines()`, `log_count()`, and
  `log_scroll()` come from `log.h` — no `g_log_*` globals in scope.
- The `handle_meters4` name was originally tied to `/meters/4` specifically.
  After T-033 the function handles both `/meters/4` (XR18) and `/meters/15`
  (X32) via the same `parse_meters4_blob` call (which now accepts n_vals 50 or
  100). The rename to `handle_meters` reflects this.
- `run_ringout()` has its own inline baseline calibration loop that does NOT
  call `handle_meters4` — it accumulates into a local `accum[]` array. Do not
  fold that loop into `handle_calibration_frame`; they serve different purposes
  (ring-out needs synchronous baseline before starting the controller, reactive
  mode builds the baseline on live RTA frames). Leave `run_ringout`'s baseline
  loop alone.
