## Goal

`XAir_ToastSaver --doctor [--fix]` — a readiness check so ToastSaver never runs
against a mixer that can't accept its notches; and an **auto pre-flight** that
runs the same check before reactive/ring-out start.

## What it checks (verified live on a real XR18)

- XR18 reachable (`/xinfo`), with a config summary (RTA source ch, FX slot).
- Every **bus 1–6 + LR** output is in **GEQ or TEQ** mode (`/bus/N/eq/mode`,
  `/lr/eq/mode`); `--fix` sets any failing output to TEQ.
- The reactive **FX slot** holds a GEQ/TEQ (`/node ,s fx/{slot}` → e.g. "TEQ ON";
  note the X32 `/node` reply address is `node`, no leading slash).
- The **RTA `/meters/4` is actually streaming** (subscribes, counts frames,
  reports peak dBFS — catches a dead/mis-tapped RTA source).
- **mic-cal** status (loaded / not configured).

## Auto pre-flight

Before reactive or ring-out runs, the same `run_doctor()` executes; if it finds
issues and `--fix` was not given, ToastSaver **aborts** with a clear message
(`--fix` to repair, `--no-preflight` to override). `run_doctor()` returns the
issue count for this.
