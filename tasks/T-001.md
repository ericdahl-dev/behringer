## Goal

Create the source and build inventory needed to compile every applicable app from https://github.com/pmaillot/X32-Behringer on this OS.

## Acceptance Criteria

- [x] The source repo is cloned or otherwise made available in a documented local path.
- [x] The target OS, architecture, compiler, libc, and package manager are recorded.
- [x] Every top-level app or utility source file is listed with its expected output binary.
- [x] Each app is classified as native CLI, native GUI, Windows-specific, library-only, parser/helper-only, or unknown.
- [x] Existing upstream build entrypoints are identified, including Makefile targets and any manual compile notes from the README.
- [x] A dependency list is produced for build tools, system libraries, and compatibility layers if needed.

## Notes

Start from upstream README and Makefile. The README says the project is C-based, relies heavily on OSC over UDP, builds a utility library from `X32lib`, and includes some Windows applications that depend on MFC or Windows libraries.

Use Patrick-Gilles Maillot's project site as product inventory context: https://sites.google.com/site/patrickmaillot/x32. Cross-check published app names against source files and Makefile targets. If a site-published app is absent from source, mark it as "not present in source" rather than "failed build".
