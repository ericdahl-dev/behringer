## Goal

Add a live ANSI terminal display to `src/XAir_ToastSaver.c` that shows the 100-bin RTA spectrum as a bar graph, marks notched bands, and shows key status at a glance. No ncurses — ANSI escape codes only.

## Display Layout

```
XAir Toast Saver  ch:4  fx:4  thr:20dB  cut:-6dB  rel:10s
──────────────────────────────────────────────────────────────
  20Hz                        1kHz                      20kHz
  |                            |                            |
█ █ █ █ █ █ █ █ █ ░ █ █ █ █ █ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░ ░   ← RTA bars
▼               ▼                                               ← notch markers
──────────────────────────────────────────────────────────────
Notched: 125Hz(-6dB 3.2s)  1kHz(-6dB 0.8s)
```

- Header line: static, printed once.
- Separator line: static.
- Frequency ruler: 3 fixed labels (20 Hz, 1 kHz, 20 kHz) aligned to their approximate column positions in the 100-character wide bar.
- RTA bar row: 100 characters, one per bin. Character selection by level relative to baseline:
  - Level < baseline + 5 dB: space ` ` (noise floor)
  - Level ≥ baseline + 5 dB: `░` (low signal)
  - Level ≥ baseline + 10 dB: `▒` (moderate)
  - Level ≥ baseline + 15 dB: `▓` (high)
  - Level ≥ baseline + threshold_dB: `█` (at/above threshold — potential feedback)
  - If the bin's GEQ par is currently notched: `N` (shows the cut is active)
- Notch marker row: `▼` placed at the column of each notched GEQ par's representative RTA bin; spaces elsewhere.
- Status line: lists all active notches with band label, cut depth, and elapsed time since notch was applied.
- Baseline indicator: when calibrating, replace the RTA bar with a progress line: `Calibrating... [████░░░░░░] 20/40 frames`.

## Acceptance Criteria

- [ ] Display updates in-place using ANSI cursor control (`\033[{row};1H` to move to the row, `\033[2K` to clear line) — do not clear the whole screen on each frame.
- [ ] Display is 100 columns wide (one character per RTA bin). If the terminal is narrower, the display still renders but may wrap — no special handling needed.
- [ ] RTA bar characters use the 5-level scheme above.
- [ ] Bins whose GEQ par is notched render as `N` regardless of current level.
- [ ] Notch marker row (`▼`) aligns with `GEQ_BIN[par-1]` column for each active notch.
- [ ] Status line lists all active notches; if none, prints `Notched: (none)`.
- [ ] Display updates at the RTA rate (~20 Hz) — one redraw per `/meters/4` packet, after detection logic runs.
- [ ] If `-v` (verbose) flag is set, skip the display and print raw text output instead (so verbose logging and the display are mutually exclusive).
- [ ] Terminal is restored on exit (cursor shown, no leftover ANSI state): print `\033[?25h` before exit.

## ANSI Reference

```c
#define ANSI_HOME       "\033[H"
#define ANSI_CLEAR_LINE "\033[2K"
#define ANSI_GOTO(r,c)  printf("\033[%d;%dH", (r), (c))
#define ANSI_HIDE_CURSOR "\033[?25l"
#define ANSI_SHOW_CURSOR "\033[?25h"
#define ANSI_RED        "\033[31m"
#define ANSI_YELLOW     "\033[33m"
#define ANSI_GREEN      "\033[32m"
#define ANSI_RESET      "\033[0m"
```

Color suggestions: `N` (notched bin) in red, `█` (threshold exceeded) in yellow, everything else default.

## Notes

- Print `ANSI_HIDE_CURSOR` on startup to prevent cursor flicker during updates.
- The display function signature: `static void draw_display(const AppState *s)`. Call it from `handle_meters4()` after detection logic, unless `s->verbose`.
- Elapsed time for the status line comes from `gettimeofday()` minus `notches[i].notched_at`.
- The ruler and header rows are at fixed row numbers (1 and 2). The RTA bar is row 5, the marker row is row 6, the status line is row 7. Print the header/ruler once on startup; only update rows 5–7 each frame.
- Use `fflush(stdout)` after each full display update.
