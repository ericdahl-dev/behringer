## Goal

Add the **action-executor plumbing** the ring-out controller drives: ramp a
chosen monitor bus fader over OSC, ensure the RTA taps that monitor, insert the
notch TEQ on the bus under test, and a **panic restore** that snaps gain back to
its start value. This is the only platform-specific half of the feature.

See [`docs/ringout-design.md`](../docs/ringout-design.md) ("Targeting", "Safety").

## OSC paths (XAir / XR18, port 10024)

```
/bus/{N}/mix/fader     ,f   {0.0..1.0}   // drive monitor gain (see cheat-sheet float↔dB)
/bus/{N}/insert/sel    ,i   {0..4}       // insert FX slot on the monitor bus (OFF,Fx1..Fx4)
/fx/{slot}/par/{nn}    ,f   {0.0..1.0}   // existing TEQ notch (send_teq_band)
/meters/4              (blob)            // RTA source — must tap the monitor mic
```

Fader float↔dB conversion: use the piecewise formula in
[`docs/xr18-xair-osc-cheatsheet.md`](../docs/xr18-xair-osc-cheatsheet.md).

## Acceptance Criteria

- [ ] New args: `--ringout-bus N` (target monitor bus), `--ringout-ceiling dB`,
      `--ringout-step dB`, `--ringout-margin dB`, `--ringout-max-notches N`.
- [ ] `ringout_set_gain(AppState*, float dB)` — converts dB→float (shared
      cheat-sheet formula) and sends `/bus/N/mix/fader`; tracks current driven
      gain in `AppState`.
- [ ] On ring-out start: record the bus's **original fader** value; ensure the
      FX-slot TEQ is inserted on the target bus (`/bus/N/insert/sel`); print a
      one-line confirmation of bus, FX slot, ceiling, and start gain.
- [ ] `ringout_panic(AppState*)` — immediately restores the bus fader to the
      recorded original value; bound to **SIGINT (Ctrl-C)** and callable on
      `RO_ABORT`. Verify the fader actually returns (read-back or log).
- [ ] RTA-tap guard: detect/log if `/meters/4` is not tracking the target monitor
      (best-effort in v1 — a clear warning is acceptable; auto-select is a later
      task), so the operator can fix the tap before ramping.
- [ ] Reuses existing UDP send + `send_teq_band`; no change to reactive behaviour.

## Notes

- Gain drive is the dangerous bit — the **ceiling is enforced in `ringout_step`
  (T-021)**; this layer additionally clamps any commanded dB to `ceiling_db` as a
  belt-and-suspenders guard before sending.
- Keep the original-fader restore robust to early exit (atexit / signal handler).
