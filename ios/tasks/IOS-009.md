## Goal

Implement `MixerConnection.swift` in the iOS app target. This supersedes the
`XR18Connection` design from IOS-005 — do not build `XR18Connection`; build
`MixerConnection` instead. It wraps `NWConnection` (UDP) and is parameterised by
`MixerModel` so it works with both the XR18 (port 10024) and X32 (port 10023)
without branching in the caller.

Key responsibilities beyond IOS-005's `XR18Connection`:
- Port and handshake path come from `MixerModel`, not hardcoded.
- Fader read (`readFader`) and write (`writeFader`) for ring-out gain control and
  restore-on-abort.
- TEQ notch send uses `OSCMessage.geqBand(slot:par:dB:)` from `ToastSaverCore`.

## File

`ios/ToastSaver/MixerConnection.swift`

## Public interface

```swift
import Network
import Combine
import ToastSaverCore

@MainActor
final class MixerConnection: ObservableObject {

    @Published private(set) var connectionState: ConnectionState = .disconnected

    enum ConnectionState: Equatable {
        case disconnected
        case connecting
        case connected
        case failed(String)
    }

    let model: MixerModel
    let host: String

    init(model: MixerModel, host: String)

    // MARK: - Lifecycle

    /// Open the UDP socket, send the model's handshake packet, wait up to 2 s
    /// for any reply (XR18 replies to /xinfo; X32 replies to /info).
    /// Sets connectionState = .connected on success, .failed on timeout.
    func connect() async

    /// Close the NWConnection and stop the keepalive timer.
    func disconnect()

    // MARK: - TEQ control

    /// Send /fx/{slot}/par/{par:02d} ,f {geqFloat(dB)}.
    /// Fire-and-forget; does not wait for acknowledgement.
    func sendNotch(slot: Int, par: Int, dB: Float)

    /// Restore a TEQ band to flat (0 dB → geqFloat = 0.5).
    func sendFlat(slot: Int, par: Int)

    // MARK: - Fader control (ring-out)

    /// Query the current fader value for a bus.
    /// Path: /bus/{bus}/mix/fader (XR18) — same path on X32.
    /// Returns the raw OSC float [0.0, 1.0], or nil on timeout.
    func readFader(bus: Int) async -> Float?

    /// Set a bus fader to a raw OSC float [0.0, 1.0].
    func writeFader(bus: Int, value: Float)
}
```

## Implementation notes

### NWConnection setup

```swift
private func makeConnection() {
    let endpoint = NWEndpoint.hostPort(
        host: NWEndpoint.Host(host),
        port: NWEndpoint.Port(rawValue: model.port)!
    )
    connection = NWConnection(to: endpoint, using: .udp)
    connection?.stateUpdateHandler = { [weak self] state in
        Task { @MainActor in
            switch state {
            case .ready:   self?.connectionState = .connected; self?.startKeepalive()
            case .failed(let e): self?.connectionState = .failed(e.localizedDescription)
            default: break
            }
        }
    }
    connection?.start(queue: .global(qos: .userInteractive))
    startReceiving()   // pump incoming packets for fader query replies
}
```

### Handshake

Use `model.handshakePath` for the packet address. Both XR18 (`/xinfo`) and X32
(`/info`) are zero-argument messages. The XR18 replies with a four-string `/xinfo`
packet; the X32 replies with a simple `/info` echo. In both cases, receiving *any*
reply within 2 seconds counts as successful connection — don't parse the payload.

```swift
func connect() async {
    connectionState = .connecting
    makeConnection()
    // Send the handshake immediately once UDP socket is ready
    // The state update handler fires .ready synchronously for UDP
    let ping = OSCMessage(model.handshakePath)
    send(Data(ping.bytes))
    // Wait up to 2 s for any reply
    do {
        try await Task.sleep(for: .seconds(2))
    } catch {}
    if case .connecting = connectionState {
        connectionState = .failed("No reply from \(host):\(model.port)")
    }
}
```

### Keepalive

Send `/xremote` every 9 seconds while connected. This matches the CLI's
`XREMOTE_TIMEOUT` constant and keeps the mixer from unsubscribing the client.
Both XR18 and X32 honour `/xremote`.

### Fader read (`readFader`)

OSC GET: send the path with no arguments and await a reply packet on the same
socket. Use a `CheckedContinuation` with a 1-second timeout. The incoming packet
has a `,f` type tag; extract the big-endian float.

```swift
func readFader(bus: Int) async -> Float? {
    let path = "/bus/\(bus)/mix/fader"
    return await withCheckedContinuation { continuation in
        pendingFaderRead = (path, continuation)
        let msg = OSCMessage(path)
        send(Data(msg.bytes))
        Task {
            try? await Task.sleep(for: .seconds(1))
            if let pending = pendingFaderRead, pending.path == path {
                pendingFaderRead = nil
                continuation.resume(returning: nil)
            }
        }
    }
}
```

The receive loop (started in `startReceiving()`) checks incoming packets for a
matching address and resolves the continuation.

### OSC packet encoding

Use `OSCMessage` from `ToastSaverCore` for all outgoing packets:

```swift
func sendNotch(slot: Int, par: Int, dB: Float) {
    let msg = OSCMessage.geqBand(slot: slot, par: par, dB: dB)
    send(Data(msg.bytes))
}

func sendFlat(slot: Int, par: Int) {
    sendNotch(slot: slot, par: par, dB: 0.0)
}

func writeFader(bus: Int, value: Float) {
    let msg = OSCMessage("/bus/\(bus)/mix/fader", .float(value))
    send(Data(msg.bytes))
}

private func send(_ data: Data) {
    connection?.send(content: data, completion: .idempotent)
}
```

## Acceptance Criteria

- [ ] `MixerConnection(model: .xr18, host: "192.168.0.64").connect()` on a reachable
  XR18 sets `connectionState` to `.connected` within 2 seconds.
- [ ] Same call to an unreachable IP sets `connectionState` to `.failed(...)`.
- [ ] `model.port` determines the UDP port — no hardcoded 10024.
- [ ] `model.handshakePath` determines the handshake address — no hardcoded `/xinfo`.
- [ ] `sendNotch(slot: 4, par: 18, dB: -6)` produces the same byte sequence as
  `XAir_ToastSaver` CLI for `/fx/4/par/18` with the corresponding cut value.
- [ ] `readFader(bus: 1)` returns a Float on a reachable mixer, nil after timeout.
- [ ] `writeFader(bus: 1, value: 0.75)` sends the correct OSC float packet.
- [ ] Keepalive sends `/xremote` every 9 ± 1 seconds (verify via packet log or mixer).
- [ ] `disconnect()` cancels connection and timer without crash or leak.

## Notes

- IOS-005 (`XR18Connection`) is superseded by this task. Do not build both.
  `NotchController` from IOS-005 is still valid — wire it to `MixerConnection` in
  IOS-010 (`RingoutSession`) rather than rebuilding it here.
- `NWConnection` on UDP goes `.ready` immediately (connectionless). The real
  liveness check is the reply to the handshake packet. Receiving *any* packet from
  the mixer's IP/port within 2 seconds is sufficient.
- The fader path `/bus/{bus}/mix/fader` is the same on XR18 and X32. If X32 bus
  paths diverge (e.g. leading zeros), add a `MixerModel.busPath(bus:)` helper in
  IOS-007 rather than branching here.
- Keep `MixerConnection` focused on transport. Do not add ring-out orchestration
  logic here — that belongs in `RingoutSession` (IOS-010).
