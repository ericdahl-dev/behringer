## Goal

Compile the upstream `X32lib` utility sources into a reusable library for the rest of the apps.

## Acceptance Criteria

- [x] All compilable `X32lib` C sources build into object files on this OS.
- [x] The object files are archived into a static library or equivalent reusable build artifact.
- [x] Public headers needed by apps are available through a documented include path.
- [x] Compiler warnings and portability problems are captured with exact file names.
- [x] At least one dependent app can link against the library in a smoke build.
- [x] Clean rebuild instructions are documented.

## Notes

The upstream README says to compile the files under `X32lib` with `-c` and archive them into a library that other programs can static-link.

## Progress

- 2026-06-19: Found `src/X32lib/libX32.a` plus object files for `Testparams`, `X32Connect`, `X32RpnCalc`, `X32logf`, `Xcparse`, `Xdump`, `Xscene2X`, `Xsprint`, and `validateIP4Dotted`.
- 2026-06-19: `src/X32lib/Makefile` builds all `*.c` files into objects and archives them into `libX32.a`.
- 2026-06-19: Dependent binaries in `src/build` confirm at least `X32`, `XAir`, and `X32Tap` can link against the library.
- 2026-06-19: Ran `make -C src/X32lib clean all`; clean rebuild succeeded with no compiler warnings emitted by GCC.
- 2026-06-19: Ran `make -C src check-build`; dependent app smoke suite passed 9/9 after library rebuild.
