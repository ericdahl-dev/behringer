## Goal

Extract the pure, testable logic from `src/XAir_ToastSaver.c` into a separate module (`src/toast_logic.c` + `src/toast_logic.h`) so that `test_toast_logic.c` (T-019) can link against it and test it in isolation. The network/OSC/display code stays in `XAir_ToastSaver.c`; only pure-logic functions move.

## Functions to extract

These five functions have no side effects and no socket/IO dependencies. Move them verbatim (removing `static`) into `toast_logic.c` and declare them in `toast_logic.h`:

| Function signature | Current location |
|---|---|
| `int bin_to_geq_par(int bin)` | `XAir_ToastSaver.c` |
| `int parse_meters4_blob(const uint8_t *blob, int blen, float *bins)` | new wrapper around inline code in `handle_meters4()` |
| `float db_to_geq_float(float dB)` | inline formula `(dB + 15) / 30` — extract as named function |
| `int detect_peak(const float *bins, const float *baseline, float threshold, int *peak_bin)` | extracted from `run_detection()` |
| `void update_baseline(float *baseline, const float *bins, int n, float alpha)` | extracted from `handle_meters4()` |

## Signatures (must match exactly — T-019 tests against these)

```c
/* toast_logic.h */
#ifndef TOAST_LOGIC_H
#define TOAST_LOGIC_H

#include <stdint.h>

/* GEQ bin lookup table (100 RTA bins → 31 GEQ pars). Exposed for tests. */
extern const int TOAST_GEQ_BIN[31];

/* Map RTA bin index (0–99) to GEQ par number (1–31). */
int bin_to_geq_par(int bin);

/* Parse a /meters/4 OSC blob into bins[100] in dBFS.
 * blob points to the raw blob data (including the 4-byte BE size header).
 * Returns 0 on success, -1 if the packet is too short or n_vals != 100. */
int parse_meters4_blob(const uint8_t *blob, int blen, float *bins);

/* Encode a dB value to GEQ float (0.0–1.0). 0 dB → 0.5, −15 dB → 0.0. */
float db_to_geq_float(float dB);

/* Detect the highest-amplitude bin that exceeds baseline[i] + threshold.
 * Sets *peak_bin to that bin's index and returns 1 if found, 0 otherwise. */
int detect_peak(const float *bins, const float *baseline, float threshold, int *peak_bin);

/* Exponential smoothing: baseline[i] = (1-alpha)*baseline[i] + alpha*bins[i] for all n. */
void update_baseline(float *baseline, const float *bins, int n, float alpha);

#endif /* TOAST_LOGIC_H */
```

## Changes to XAir_ToastSaver.c

1. Add `#include "toast_logic.h"`.
2. Remove the extracted functions (or keep `static` wrappers that call through if simpler).
3. The `GEQ_BIN` array moves to `toast_logic.c` as `const int TOAST_GEQ_BIN[31]`. `XAir_ToastSaver.c` references it via the extern in the header.
4. `GEQ_LABEL` stays in `XAir_ToastSaver.c` (it's only used for display/logging).

## Notes

- `parse_meters4_blob` is a new named wrapper: extract the int16→float conversion loop out of `handle_meters4()` and call `parse_meters4_blob()` from there. The header/count validation goes into the new function.
- `detect_peak` contains only the "find peak bin above threshold" logic — NOT the release logic or the OSC send. Those stay in `run_detection()` in `XAir_ToastSaver.c`.
- `update_baseline` is called from `handle_meters4()` after baseline is ready; move only the smoothing loop, not the calibration accumulation.
