## Goal

Create the Xcode project and Swift Package layout for the iOS Toast Saver app. The repo layout separates platform-independent detection logic (a Swift Package, testable on Linux) from the iOS app target (Xcode, requires macOS).

## Directory layout

```
ios/
  ToastSaverCore/          ← Swift Package: pure detection logic, no Apple frameworks
    Package.swift
    Sources/
      ToastSaverCore/
        GEQMap.swift
        FeedbackDetector.swift
        BaselineTracker.swift
        NarrownessFilter.swift
        OSCPacket.swift
    Tests/
      ToastSaverCoreTests/
        FeedbackDetectorTests.swift
        NarrownessFilterTests.swift
  ToastSaver.xcodeproj/    ← iOS app (create on Mac)
    ToastSaver/
      ToastSaverApp.swift
      ContentView.swift
      AudioCaptureEngine.swift
      FFTEngine.swift
      XR18Connection.swift
```

## Package.swift

```swift
// swift-tools-version: 5.9
import PackageDescription

let package = Package(
    name: "ToastSaverCore",
    platforms: [.iOS(.v16), .macOS(.v13)],
    products: [
        .library(name: "ToastSaverCore", targets: ["ToastSaverCore"]),
    ],
    targets: [
        .target(name: "ToastSaverCore", dependencies: []),
        .testTarget(name: "ToastSaverCoreTests", dependencies: ["ToastSaverCore"]),
    ]
)
```

**No external dependencies.** Do not add any SPM packages. All detection and OSC logic is written from scratch — it is simple enough not to need a library.

## Xcode project setup (on Mac)

- File → New → Project → iOS App
- Product name: `ToastSaver`
- Bundle ID: `com.skeyelab.ToastSaver`
- Swift, SwiftUI, minimum deployment iOS 16.0
- Add `ToastSaverCore` package via File → Add Package Dependencies → local path `../ToastSaverCore`
- Add `Network.framework` and `Accelerate.framework` to the app target (both are system frameworks, no SPM entry needed)
