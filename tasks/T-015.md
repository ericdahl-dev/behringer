## Goal

Implement the core feedback destruction loop in `src/XAir_ToastSaver.c`: detect feedback spikes in the 100-bin RTA, map the peak bin to a TEQ band, apply a notch cut via OSC, and automatically release the cut when the level subsides.

## Context

After baseline is established (T-014), each incoming `/meters/4` frame exposes `AppState.bins[100]` (dBFS) and `AppState.baseline[100]` (smoothed noise floor). A feedback event is a bin that exceeds `baseline[i] + threshold_dB`. The spike is mapped to the nearest 1/3-octave GEQ band (31 bands), a notch cut is sent to the TEQ in the configured FX slot, and the band is monitored for release.

The full bin→GEQ par lookup table and OSC paths are documented in `docs/xr18-meters-osc.md` and `docs/xr18-geq-osc.md`.

## TEQ OSC Paths

FX slot TEQ (GEQ/TEQ loaded as insert effect, par/01–31 are the 31 bands, par/32 is master):

```
/fx/{slot}/par/{nn} ,f {float_val}
```

- `{slot}` = 1–4 (from `-s` arg)
- `{nn}` = zero-padded 2-digit parameter number (01–31)
- `{float_val}` = `(dB + 15) / 30.0`  →  flat = 0.5, −6 dB = 0.3, −9 dB = 0.2, −12 dB = 0.1

To restore a band to flat: send `float_val = 0.5`.

## GEQ Band → RTA Bin Lookup Table

Static mapping (calibrated, from docs). Array index = GEQ par number − 1 (0-based).

```c
static const int GEQ_BIN[31] = {
     0,  3,  7, 10, 13, 16, 20, 23, 26, 30,   /* 20–160 Hz  (par 01–10) */
    33, 36, 39, 43, 46, 49, 53, 56, 59, 63,   /* 200 Hz–1.6 kHz (par 11–20) */
    66, 69, 72, 76, 79, 82, 86, 89, 92, 96,   /* 2–12.5 kHz (par 21–30) */
    99                                          /* 20 kHz (par 31) */
};

/* Map an RTA bin index (0–99) to GEQ par number (1–31) */
static int bin_to_geq_par(int bin) {
    int best = 0, best_dist = 999;
    for (int i = 0; i < 31; i++) {
        int d = abs(GEQ_BIN[i] - bin);
        if (d < best_dist) { best_dist = d; best = i; }
    }
    return best + 1;  /* 1-based par number */
}
```

## Notch State

Add to `AppState`:

```c
typedef struct {
    float   cut_val;        /* float sent to TEQ (0.0–1.0); 0.5 = flat = inactive */
    double  notched_at;     /* gettimeofday seconds when notch was applied */
    int     active;         /* 1 if this band is currently notched */
} NotchState;

NotchState notches[31];     /* index 0 = par 01 */
```

## Acceptance Criteria

- [ ] After baseline is ready, each frame: for each bin `i`, compute `excess = bins[i] - baseline[i]`. Collect all bins where `excess >= threshold_dB`.
- [ ] If any bins exceed threshold, find the peak bin (highest `bins[i]` among triggered bins). Map it to GEQ par via `bin_to_geq_par()`.
- [ ] If that GEQ par is not already notched (`notches[par-1].active == 0`), send the notch OSC command and record the notch:
  ```
  /fx/{slot}/par/{nn:02d} ,f {cut_float}
  ```
  where `cut_float = (cut_dB + 15.0) / 30.0` (e.g. −6 dB → 0.3).
- [ ] Print on each new notch: `[notch] par={nn} ({freq_hz} Hz) cut={cut_dB} dB  bin={peak_bin}`.
- [ ] Release logic: on each frame, for each active notch, check whether the corresponding GEQ bin's current level has dropped below `baseline[GEQ_BIN[par-1]] + threshold_dB / 2.0` continuously. Track a `release_hold` counter per band; if the condition is met for `release_sec * 20` consecutive frames, restore the band: send `float_val = 0.5`, clear `notches[par-1].active`. Print: `[release] par={nn} ({freq_hz} Hz) after {elapsed:.1f}s`.
- [ ] On SIGINT, the cleanup loop (stub from T-013) iterates all 31 bands; for any active notch, sends the restore OSC command before exit. Print: `[cleanup] restoring {n} band(s)`.
- [ ] GEQ_BIN array and bin_to_geq_par() are defined in the file (not a separate module).

## Notes

- Only one new notch per frame — if multiple bins trigger, pick the highest-level bin and notch it. Subsequent frames will catch additional peaks if they persist.
- Do not re-notch an already-notched band unless the cut depth changes (not implemented in this task).
- The release hold counter must reset to 0 the moment the level exceeds the release threshold again, so a band is only released after a sustained quiet period.
- Use `gettimeofday()` for the elapsed-time logging; do not use `time()` (1-second resolution is too coarse for display).
