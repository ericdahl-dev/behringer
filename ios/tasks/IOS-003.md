## Goal

Implement `FFTEngine.swift` in the iOS app target. Takes a block of PCM samples from the audio capture engine, applies a Hann window, runs a real FFT via `vDSP`, and returns a power spectrum in dBFS. Also provides the bin→GEQ-par mapping calibrated to the actual FFT bin resolution.

## File

`ios/ToastSaver/FFTEngine.swift`

## Public interface

```swift
import Accelerate

final class FFTEngine {
    let fftSize: Int        // must be power of 2; default 2048
    let sampleRate: Double  // from AVAudioSession, typically 44100 or 48000

    init(fftSize: Int = 2048, sampleRate: Double = 48000)

    /// Process one buffer of PCM samples.
    /// - Parameter samples: exactly fftSize Float32 samples
    /// - Returns: fftSize/2 power values in dBFS (0 dBFS = full scale)
    func process(_ samples: [Float]) -> [Float]

    /// Map an FFT bin index (0 ..< fftSize/2) to the nearest GEQ par (1–31).
    /// Uses the same 1/3-octave centre frequencies as GEQMap.bins,
    /// recalculated for this engine's fftSize and sampleRate.
    func geqPar(forBin bin: Int) -> Int

    /// Precomputed GEQ bin indices for fftSize and sampleRate.
    /// geqBins[i] is the FFT bin index closest to GEQ par i+1's centre frequency.
    private(set) var geqBins: [Int]  // length 31
}
```

## FFT implementation

```swift
func process(_ samples: [Float]) -> [Float] {
    precondition(samples.count == fftSize)

    // 1. Apply Hann window
    var windowed = [Float](repeating: 0, count: fftSize)
    vDSP_vmul(samples, 1, window, 1, &windowed, 1, vDSP_Length(fftSize))

    // 2. Split into real/imaginary for vDSP
    var realp = [Float](repeating: 0, count: fftSize / 2)
    var imagp = [Float](repeating: 0, count: fftSize / 2)
    windowed.withUnsafeBytes { ptr in
        var splitComplex = DSPSplitComplex(realp: &realp, imagp: &imagp)
        let typedPtr = ptr.bindMemory(to: DSPComplex.self)
        vDSP_ctoz(typedPtr.baseAddress!, 2, &splitComplex, 1, vDSP_Length(fftSize / 2))
    }

    // 3. Forward FFT
    var splitComplex = DSPSplitComplex(realp: &realp, imagp: &imagp)
    vDSP_fft_zrip(fftSetup, &splitComplex, 1, log2n, FFTDirection(FFT_FORWARD))

    // 4. Compute magnitude squared
    var magnitudes = [Float](repeating: 0, count: fftSize / 2)
    vDSP_zvmags(&splitComplex, 1, &magnitudes, 1, vDSP_Length(fftSize / 2))

    // 5. Convert to dBFS
    // Scale: each magnitude² is relative to (fftSize/2)² at full scale
    let scale = 1.0 / Float(fftSize * fftSize / 4)
    var scaled = magnitudes.map { $0 * scale }
    var db = [Float](repeating: 0, count: fftSize / 2)
    var len = Int32(fftSize / 2)
    vDSP_vdbcon(&scaled, 1, [10.0], &db, 1, vDSP_Length(fftSize / 2), 0)  // 0 = power
    return db
}
```

Create `fftSetup` with `vDSP_create_fftsetup(log2n, FFTRadix(kFFTRadix2))` in `init`, destroy with `vDSP_destroy_fftsetup` in `deinit`. Create the Hann window once in `init` with `vDSP_hann_window(&window, vDSP_Length(fftSize), Int32(vDSP_HANN_NORM))`.

## geqBins calculation

GEQ centre frequencies in Hz (31 bands, 1/3-octave, ISO):
```
[20, 25, 31.5, 40, 50, 63, 80, 100, 125, 160, 200, 250, 315, 400, 500,
 630, 800, 1000, 1250, 1600, 2000, 2500, 3150, 4000, 5000, 6300, 8000,
 10000, 12500, 16000, 20000]
```

FFT bin→Hz: `hz(bin) = Double(bin) * sampleRate / Double(fftSize)`
Hz→bin: `bin(hz) = Int(round(hz * Double(fftSize) / sampleRate))`

```swift
private func computeGeqBins() -> [Int] {
    let freqs: [Double] = [20, 25, 31.5, 40, 50, 63, 80, 100, 125, 160,
                            200, 250, 315, 400, 500, 630, 800, 1000, 1250,
                            1600, 2000, 2500, 3150, 4000, 5000, 6300, 8000,
                            10000, 12500, 16000, 20000]
    return freqs.map { hz in
        min(Int(round(hz * Double(fftSize) / sampleRate)), fftSize / 2 - 1)
    }
}
```

## Note on bin count vs. GEQMap

`GEQMap.bins` in `ToastSaverCore` is calibrated for a **100-bin** RTA (the XR18's `/meters/4`). `FFTEngine.geqBins` is calibrated for `fftSize/2` bins at the actual sample rate. Use `FFTEngine.geqBins` everywhere in the iOS app; use `GEQMap.bins` only if you ever fall back to parsing the XR18's OSC RTA blobs.

## Acceptance Criteria

- [ ] `FFTEngine(fftSize: 2048, sampleRate: 48000)` initialises without crashing.
- [ ] `process(_:)` with a 1 kHz sine wave at 48 kHz, 2048 samples: peak bin is within ±2 bins of `Int(round(1000 * 2048 / 48000))` = bin 43.
- [ ] `geqBins[17]` (1 kHz, 0-based index) ≈ 43 for 2048/48000.
- [ ] `process(_:)` with all-zero input returns all values ≤ -80 dBFS.
- [ ] `fftSetup` is freed in `deinit` (no leak detectable under Instruments).
- [ ] No `print` or `os_log` calls in the engine — it runs in the audio thread.

## Notes

- Run `process(_:)` on a dedicated serial `DispatchQueue` or `OperationQueue` — never on the AVAudioEngine tap callback thread and never on the main thread.
- `vDSP_fft_zrip` modifies the input buffer in place; always pass a copy.
- For a 2048-point FFT at 48 kHz, frequency resolution is 48000/2048 ≈ 23.4 Hz/bin. The highest GEQ bin (20 kHz) is at bin 853 — well within the 1024-bin output.
