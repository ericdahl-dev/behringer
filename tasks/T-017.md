## Goal

Wire `XAir_ToastSaver` into the `src/Makefile` build system and add it to the build smoke test so it is verified by `make check-build`.

## Context

The `src/Makefile` has two build tiers: `TARGETS` (built by `make all`) and `MORE_TARGETS` (built by `make lots`). New tools with no unusual deps go into `MORE_TARGETS`. The build smoke test is `src/test_build.py`, which compiles each target and checks the output binary exists. The packaged binary list is `PACKAGED_BINARIES` in the Makefile — adding a binary here means it is included in `make package`.

`XAir_ToastSaver` only needs `-lm` beyond the standard X32lib link flags. It does NOT need `-pthread` or `-lncursesw`.

## Acceptance Criteria

- [ ] `src/Makefile`: `XAir_ToastSaver` added to `MORE_TARGETS`.
- [ ] `src/Makefile`: Makefile rule added:
  ```makefile
  XAir_ToastSaver: X32lib
  	$(CC) $(CFLAGS) -o $(BUILD)/$@ $@.c $(LDFLAGS)
  ```
  (`-lm` is already covered by `LIBS := m X32` in the existing `LDFLAGS`.)
- [ ] `src/Makefile`: `XAir_ToastSaver` added to `PACKAGED_BINARIES`.
- [ ] `make lots` (run from `src/`) completes without errors and `src/build/XAir_ToastSaver` exists.
- [ ] `src/test_build.py`: `XAir_ToastSaver` added to the list of expected binaries checked after `make lots`.
- [ ] `make check-build` passes with `XAir_ToastSaver` included in the pass count.

## Notes

- Read the existing Makefile at `src/Makefile` and `src/test_build.py` before editing — follow the exact patterns already used for tools like `XAir_Command`.
- Do not modify `TARGETS` (the `make all` default set) — `XAir_ToastSaver` is a specialist tool and should only build under `make lots`.
- After adding to `PACKAGED_BINARIES`, run `make package` and confirm `dist/bin/XAir_ToastSaver` is present.
