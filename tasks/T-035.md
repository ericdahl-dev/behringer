## Goal

Split the `AppState` god-object in `cli/XAir_ToastSaver.c` into two structs:
- `AppConfig` — everything set at parse time, immutable after `main()` finishes
  parsing; passed as `const AppConfig *` to most functions
- `AppRuntime` — mutable state that changes during a run (socket, RTA buffers,
  detection state, ring-out bookkeeping)

This makes the code self-documenting about what each function mutates and opens
the door to unit-testing runtime logic without the config.

## Current state

`AppState` (in `XAir_ToastSaver.c`) contains ~35 fields mixing config and
runtime:

```c
typedef struct {
    /* config */
    const MixerModel *model;
    char   ip[20];
    int    channel, fx_slot;
    float  threshold_dB, cut_dB, release_sec;
    int    verbose, doctor, doctor_fix, no_preflight;
    int    ringout, ro_bus, ro_supervised, ro_max_notches;
    float  ro_ceiling_db, ro_step_db, ro_margin_db;
    char   ro_save_profile[256], ro_load_profile[256];

    /* socket */
    OscConn conn;

    /* RTA runtime */
    float   bins[100], baseline[100], baseline_accum[100];
    int     baseline_count, baseline_ready;
    float   mic_corr[100];

    /* detection runtime */
    ToastState toast;
    double  notched_at[31];
    float   ro_notch_at_gain[31];

    /* ring-out runtime */
    float   ro_orig_fader;
    int     ro_orig_captured;
    float   ro_cur_gain_db;

    /* doctor / preflight */
    int     doctor, doctor_fix, no_preflight;
} AppState;
```

## Target state

```c
typedef struct {
    const MixerModel *model;
    char   ip[20];
    int    channel, fx_slot;
    float  threshold_dB, cut_dB, release_sec;
    int    verbose, no_preflight;
    int    doctor, doctor_fix;
    int    ringout, ro_bus, ro_supervised, ro_max_notches;
    float  ro_ceiling_db, ro_step_db, ro_margin_db;
    char   ro_save_profile[256], ro_load_profile[256];
} AppConfig;

typedef struct {
    OscConn conn;
    float   bins[100], baseline[100], baseline_accum[100];
    int     baseline_count, baseline_ready;
    float   mic_corr[100];
    ToastState toast;
    double  notched_at[31];
    float   ro_notch_at_gain[31];
    float   ro_orig_fader;
    int     ro_orig_captured;
    float   ro_cur_gain_db;
} AppRuntime;
```

All internal functions that currently take `AppState *s` become
`(const AppConfig *cfg, AppRuntime *rt)` or, where config-only read access
suffices, `(const AppConfig *cfg)`.

`main()` declares `AppConfig cfg; AppRuntime rt; memset(&cfg, 0, ...);
memset(&rt, 0, ...);` and initialises them separately.

## Mechanical substitution guide

| Old access | New access |
|---|---|
| `s->model`, `s->ip`, `s->channel` | `cfg->model`, `cfg->ip`, `cfg->channel` |
| `s->conn` | `rt->conn` |
| `s->bins`, `s->baseline`, `s->mic_corr` | `rt->bins`, `rt->baseline`, `rt->mic_corr` |
| `s->toast` | `rt->toast` |
| `s->ro_orig_fader`, `s->ro_orig_captured` | `rt->ro_orig_fader`, `rt->ro_orig_captured` |
| `s->notched_at`, `s->ro_notch_at_gain` | `rt->notched_at`, `rt->ro_notch_at_gain` |
| `s->ro_cur_gain_db` | `rt->ro_cur_gain_db` |
| `s->verbose`, `s->doctor`, `s->ringout` | `cfg->verbose`, `cfg->doctor`, `cfg->ringout` |
| `s->mic_corr` (set by `load_mic_cal`) | `rt->mic_corr` — `load_mic_cal(const AppConfig*, AppRuntime*)` |

## Affected functions (all in `XAir_ToastSaver.c`)

Every static function that takes `AppState *s` needs its signature updated:
- `subscribe_meters(AppState *s)` → `subscribe_meters(const AppConfig*, AppRuntime*)`
- `ringout_set_gain` → `(const AppConfig*, AppRuntime*, float dB)`
- `ringout_panic` → `(const AppConfig*, AppRuntime*)`
- `run_doctor` → `(const AppConfig*, AppRuntime*, int fix, DoctorItem*, int*)`
- `handle_meters4` (or `handle_meters` after T-038) → `(const AppConfig*, AppRuntime*, blob, blen)`
- `run_ringout` → `(const AppConfig*, AppRuntime*)`
- `run_reactive` (from T-034) → `(const AppConfig*, AppRuntime*)`
- `cleanup_notches` → `(const AppConfig*, AppRuntime*)`
- `send_teq_band` → `(const AppConfig*, AppRuntime*, int par, float val)`
- `make_reactive_ctx` → `(const AppConfig*, const AppRuntime*)`
- `load_mic_cal` → `(AppRuntime*, const char *path)`  (reads path from arg, not config)
- `ringout_save_profile`, `ringout_load_profile` → `(const AppConfig*, AppRuntime*, ...)`
- `doc_report` → `(const AppConfig*, AppRuntime*, ...)` or split s out

## Notes

- `load_mic_cal` is called during arg parsing (from `getopt` case
  `OPT_MIC_CAL`), before `AppRuntime` is fully initialised except for
  `mic_corr`, which is zeroed by `memset`. This is fine — just call
  `load_mic_cal(&rt, optarg)` during parsing.
- `make_reactive_ctx` builds a `TuiReactiveCtx` from AppState fields — update
  it to read from both `cfg` and `rt`.
- This is a large mechanical change. Go function-by-function in file order.
  Compile after each function update to catch typos early (`make XAir_ToastSaver`).
- Do not change any logic, thresholds, flow, or external behaviour — only the
  struct split and signature updates.
