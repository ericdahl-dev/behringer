## Goal

Implement `AudioCaptureEngine.swift`. Configures `AVAudioSession` to prefer a connected USB audio interface; falls back to the built-in microphone if none is present. Installs a tap on the `AVAudioEngine` input node, accumulates PCM samples into 2048-sample blocks, feeds each block to `FFTEngine`, and publishes the resulting power spectrum.

## File

`ios/ToastSaver/AudioCaptureEngine.swift`

## Public interface

```swift
import AVFoundation
import Combine

final class AudioCaptureEngine: ObservableObject {
    /// Current power spectrum: fftSize/2 values in dBFS. Published on main thread.
    @Published private(set) var spectrum: [Float] = []

    /// Active input source description (e.g. "USB Audio" or "Built-in Microphone").
    @Published private(set) var inputSourceName: String = "—"

    /// True while capture is running.
    @Published private(set) var isRunning: Bool = false

    init(fftEngine: FFTEngine)

    /// Request microphone permission then start capture. Throws on denial or engine error.
    func start() async throws

    /// Stop capture and deactivate audio session.
    func stop()
}
```

## AVAudioSession setup

```swift
private func configureSession() throws {
    let session = AVAudioSession.sharedInstance()
    // .measurement mode: disables AGC, disables system noise reduction
    // Correct for a measurement mic; also correct for the built-in mic in this use case
    try session.setCategory(.record, mode: .measurement, options: [.allowBluetooth])
    try session.setActive(true)

    // Prefer USB input if available
    if let usbInput = session.availableInputs?.first(where: {
        $0.portType == .usbAudio
    }) {
        try session.setPreferredInput(usbInput)
        inputSourceName = usbInput.portName
    } else {
        inputSourceName = session.currentRoute.inputs.first?.portName ?? "Built-in Microphone"
    }

    // Request 48 kHz — most USB interfaces run at 48 kHz
    try session.setPreferredSampleRate(48000)
    try session.setPreferredIOBufferDuration(1024 / 48000)  // ~21 ms
}
```

## AVAudioEngine tap

```swift
private func installTap() {
    let inputNode = engine.inputNode
    let format = inputNode.inputFormat(forBus: 0)

    // Update FFT engine sample rate to match actual session rate
    // (session may have settled at 44100 if 48000 was unavailable)
    fftEngine = FFTEngine(fftSize: 2048, sampleRate: format.sampleRate)

    inputNode.installTap(onBus: 0, bufferSize: 512, format: format) { [weak self] buffer, _ in
        self?.handleBuffer(buffer)
    }
}
```

## Buffer accumulation and FFT dispatch

The tap callback may deliver buffers smaller than 2048 samples. Accumulate into a ring, dispatch full blocks to the FFT queue.

```swift
private var accumulator: [Float] = []
private let fftQueue = DispatchQueue(label: "toast.fft", qos: .userInteractive)

private func handleBuffer(_ buffer: AVAudioPCMBuffer) {
    guard let channelData = buffer.floatChannelData?[0] else { return }
    let count = Int(buffer.frameLength)
    accumulator.append(contentsOf: UnsafeBufferPointer(start: channelData, count: count))

    while accumulator.count >= fftEngine.fftSize {
        let block = Array(accumulator.prefix(fftEngine.fftSize))
        accumulator.removeFirst(fftEngine.fftSize)
        fftQueue.async { [weak self] in
            guard let self else { return }
            let result = self.fftEngine.process(block)
            DispatchQueue.main.async {
                self.spectrum = result
            }
        }
    }
}
```

## Route change handling

```swift
NotificationCenter.default.addObserver(
    forName: AVAudioSession.routeChangeNotification,
    object: nil,
    queue: .main
) { [weak self] notification in
    guard let reason = notification.userInfo?[AVAudioSessionRouteChangeReasonKey] as? UInt,
          let changeReason = AVAudioSession.RouteChangeReason(rawValue: reason) else { return }
    switch changeReason {
    case .newDeviceAvailable:
        // USB interface plugged in — restart to prefer it
        Task { try? await self?.restart() }
    case .oldDeviceUnavailable:
        // USB interface unplugged — fall back to built-in mic
        Task { try? await self?.restart() }
    default:
        break
    }
}
```

`restart()` calls `stop()` then `start()`.

## Microphone permission

```swift
func start() async throws {
    // iOS 17+
    if #available(iOS 17.0, *) {
        guard await AVAudioApplication.requestRecordPermission() else {
            throw CaptureError.permissionDenied
        }
    } else {
        let granted = await withCheckedContinuation { continuation in
            AVAudioSession.sharedInstance().requestRecordPermission { continuation.resume(returning: $0) }
        }
        guard granted else { throw CaptureError.permissionDenied }
    }
    try configureSession()
    try engine.start()
    installTap()
    isRunning = true
}
```

Add `NSMicrophoneUsageDescription` to `Info.plist`:
```
"Listens for feedback frequencies to protect the audience during toasts."
```

## Acceptance Criteria

- [ ] App requests microphone permission on first `start()` call.
- [ ] When a USB audio interface is connected, `inputSourceName` shows the interface name (e.g. "Focusrite USB Audio").
- [ ] When no USB interface is connected, capture uses the built-in microphone and `inputSourceName` shows "Built-in Microphone" (or the actual system name).
- [ ] Plugging a USB interface while running triggers a restart and `inputSourceName` updates.
- [ ] Unplugging a USB interface while running restarts on the built-in mic without crashing.
- [ ] `spectrum` is published at approximately `sampleRate / fftSize` Hz (≈23 Hz at 48kHz/2048).
- [ ] No audio session errors printed to console during normal operation.
- [ ] `stop()` removes the tap and deactivates the session cleanly.

## Notes

- Use `.measurement` mode — it disables iOS automatic gain control and noise suppression. This is critical for a measurement mic; without it, iOS will try to "improve" the input and corrupt the frequency response.
- The built-in mic on iPhone is good enough to detect feedback. It is omni-directional and has reasonable frequency response from 20 Hz to 20 kHz. A measurement mic will be more accurate, but the built-in mic is a valid fallback at a gig.
- `AVAudioEngine` must be started AFTER `AVAudioSession.setActive(true)` and AFTER `installTap`.
- The tap closure is called on an internal AVAudioEngine thread — never update `@Published` properties directly from it.
