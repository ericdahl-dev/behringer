## Goal

Wire the pure controller (T-021) and the gain-drive plumbing (T-022) together
into a new **supervised `--ringout` mode** in `cli/XAir_ToastSaver.c`: ramp a
monitor up, notch each ring as it appears, stop at the ceiling / target margin /
max notches, and report the result.

See [`docs/ringout-design.md`](../docs/ringout-design.md).

## Acceptance Criteria

- [x] `--ringout` selects ring-out mode (reactive remains the default). Mode is
      mutually exclusive with the live-protect loop (separate `run_ringout`).
- [x] Per `/meters/4` frame: call `ringout_step`, and execute the returned
      action — `RO_RAISE_GAIN`/`RO_BACK_OFF` → `ringout_set_gain`;
      `RO_PLACE_NOTCH` → `send_teq_band(par, db_to_geq_float(cut_db))` and record
      in `notches[]`; `RO_HOLD` → wait; `RO_DONE`/`RO_ABORT` → finish.
- [x] **Supervised:** `--ringout-supervised` pauses for Enter before each
      `RO_RAISE_GAIN` (`q` aborts); without it runs auto but still honours Ctrl-C.
- [x] Live progress to the terminal: per-action log lines with current driven
      gain, margin to ceiling, and notch placements.
- [x] On completion print a summary: list of notched bands, **gain-before-feedback
      margin achieved**, and stop reason (ceiling / margin / max-notches / abort).
- [x] Builds via `make`; `--help` documents the new flags; no regression to
      reactive mode (existing `check` tests still pass).

## Notes

- Keep `XAir_ToastSaver.c` thin — all decisions come from `ringout_step`; this
  task is glue + presentation, not new control logic.
- The in-memory result (bands + depths + margin) is the object T-024 persists;
  define it here as a small struct so T-024 only adds serialization.

## Progress

2026-06-29: Implemented the `--ringout` control loop in `run_ringout`
(`XAir_ToastSaver.c`), linked `ringout_logic.c` into the build. Flow: capture
fader + insert TEQ (T-022) → **calibrate the noise floor** (BASELINE_FRAMES at
start gain) → drive `ringout_step()` once per `/meters/4` frame, executing
RAISE/BACK_OFF via `ringout_set_gain`, PLACE_NOTCH via `send_teq_band` (recorded
in `notches[]` for display + cleanup), DONE/ABORT to finish. Per-action progress
lines + a final summary (bands, margin, reason). **Restore policy:** the fader is
always returned to the operator's start level (`ringout_panic`); notches are
**kept only on a clean completion**, reverted otherwise.

Deviations from the original AC text, by design:
1. Supervised flag is **`--ringout-supervised`**, not `--ringout-step` — the
   latter is already the dB ramp increment (T-022).
2. Supervised pauses **before raises only**, not before each notch — pausing
   before a notch would let the ring sustain (unsafe).
3. Baseline is **calibrated once and held fixed** during the run, not updated
   per frame — so a developing ring isn't absorbed into the noise floor.

Verified: `make all` clean (no `-Wall` warnings); `make check` 45/16/22 green;
`--help` + arg validation smoke-tested. Live mixer/emulator validation is T-025.
