## Goal

Consolidate `esp32/` (X32 emulator + ESP-series tasks) and `esp32-link/`
(X32Link firmware, X32MidiClock firmware, Ableton Link + Unity submodules,
LNK/MCK/TSV tasks) into a single `esp32/` directory. This is Phase 2 of
the repo reorg started in commit `bb1fd9d`.

## Current layout

```
esp32/
  X32_emulator/
  tasks/            ← ESP-001..006 (idPrefix: ESP)
  tests/
  .ordna/config.yaml

esp32-link/
  X32Link/
  X32MidiClock/
  lib/
    link/           ← submodule: github.com/Ableton/link
    unity/          ← submodule: github.com/ThrowTheSwitch/Unity
  test/
  tasks/            ← LNK-001..012, MCK-001..006, TSV-001..006
  .ordna/config.yaml
  AGENTS.md
```

## Target layout

```
esp32/
  X32_emulator/     ← unchanged
  X32Link/          ← from esp32-link/X32Link/
  X32MidiClock/     ← from esp32-link/X32MidiClock/
  lib/
    link/           ← submodule (moved, not re-cloned)
    unity/          ← submodule (moved, not re-cloned)
  test/             ← from esp32-link/test/
  tasks/            ← merged: ESP + LNK + MCK + TSV series
  .ordna/config.yaml
  AGENTS.md
```

## Steps

### 1. Move submodules safely

Submodules cannot be moved with plain `cp` or `mv` — the `.gitmodules` entries
and the parent repo's index must be updated together.

For each submodule in `esp32-link/lib/`:

```bash
# Example for lib/link:
git mv esp32-link/lib/link esp32/lib/link
```

Then edit `.gitmodules` to update the `path` fields:

```
[submodule "esp32/lib/link"]
    path = esp32/lib/link
    url = https://github.com/Ableton/link

[submodule "esp32/lib/unity"]
    path = esp32/lib/unity
    url = https://github.com/ThrowTheSwitch/Unity.git
```

Run `git submodule sync` after editing `.gitmodules`.

### 2. Move firmware and test directories

```bash
git mv esp32-link/X32Link      esp32/X32Link
git mv esp32-link/X32MidiClock esp32/X32MidiClock
git mv esp32-link/test         esp32/test
```

### 3. Merge task files

```bash
git mv esp32-link/tasks/LNK-*.md esp32/tasks/
git mv esp32-link/tasks/MCK-*.md esp32/tasks/
git mv esp32-link/tasks/TSV-*.md esp32/tasks/
```

### 4. Merge ordna config

The two `.ordna/config.yaml` files use different `idPrefix` values. The merged
config should support all four prefixes. Ordna's `idPrefix` is a single value,
but since all task files already exist with their IDs baked in, no renaming is
needed — just pick the most general config and note the prefixes in a comment:

```yaml
# Task prefixes in use: ESP (emulator), LNK (X32Link), MCK (MidiClock), TSV (ToastSaver-HW)
storage: file
tasksDir: tasks
schema: ordna
statuses: [todo, doing, done]
idPrefix: ESP
zeroPaddedIds: 3
```

### 5. Copy AGENTS.md

```bash
cp esp32-link/AGENTS.md esp32/AGENTS.md   # or merge if esp32/ already has one
```

### 6. Remove esp32-link/

```bash
git rm -r esp32-link/
```

Verify `.gitmodules` no longer references `esp32-link/lib/link` or
`esp32-link/lib/unity`.

### 7. Update any path references

Search for hardcoded `esp32-link/` paths in:
- `esp32/X32Link/*.ino`, `*.cpp`, `*.h` (platformio paths, include paths)
- `esp32/test/Makefile`
- Root `AGENTS.md` or any docs

```bash
grep -r "esp32-link" esp32/ docs/ AGENTS.md 2>/dev/null
```

Fix any hits.

### 8. Verify build

```bash
cd esp32/test && make
```

All host tests should pass after the move.

### 9. Commit

```bash
git add .gitmodules esp32/ && git rm -r esp32-link/
git commit -m "reorg: merge esp32-link/ into esp32/"
```

## Acceptance Criteria

- [ ] `esp32/` contains X32_emulator, X32Link, X32MidiClock, lib/link, lib/unity, test, tasks.
- [ ] `esp32-link/` no longer exists.
- [ ] `.gitmodules` paths updated to `esp32/lib/link` and `esp32/lib/unity`; old paths removed.
- [ ] `git submodule status` shows both submodules at their original commits (no re-clone needed).
- [ ] `esp32/tasks/` contains all ESP, LNK, MCK, and TSV task files.
- [ ] `esp32/test/` host tests pass (`make` in esp32/test/).
- [ ] `grep -r "esp32-link" .` returns no hits outside of git history.

## Notes

- Do NOT use `cp -r` + `rm -rf` for the submodule directories — git will lose
  the submodule registration and the working tree will be detached. Always use
  `git mv` for submodule paths, then update `.gitmodules` manually.
- Run `git submodule sync && git submodule update` after moving to confirm the
  submodules resolve correctly at their new paths.
- The `esp32-link/lib/link` submodule has modified content (shown in `git status`
  at time of writing — commit `bb1fd9d`). Investigate what changed before moving;
  if it is just index churn from the codebase-memory indexer, discard with
  `git -C esp32-link/lib/link checkout .` first.
