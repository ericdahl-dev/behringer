## Goal

Compile every native command-line utility from X32-Behringer that can reasonably run on this OS.

## Acceptance Criteria

- [x] Each native CLI utility from the inventory has a build command or Makefile target.
- [x] Each new app build follows red-green-refactor: first add or expose a failing build/test/smoke check, then make the smallest change to pass.
- [x] Network/OSC utilities link with the correct socket libraries for this OS.
- [x] File conversion and parser tools build without requiring an X32 console.
- [x] Runtime smoke checks are run for binaries that support `--help`, usage output, no-argument output, or harmless file-only behavior.
- [x] Utilities that cannot compile are listed with the exact compiler or linker failure.
- [x] Successful binaries are collected in a documented output directory.

## Notes

Likely candidates include X32/XAir command, scene, preset, library, WAV/X-Live, marker, tap, fade, MIDI/OSC, and related terminal utilities. Use T-001 as the source of truth for the final list.

TDD rule: one app at a time. Add failing build target or smoke check, run it red, patch source/Makefile minimally, run green, then continue.

For apps that benefit from interactive UI on this OS, use the `X32Tap` TUI approach as the model: keep reusable logic in a testable module, cover it with a headless test binary, and keep curses/TUI behavior as a thin shell.
