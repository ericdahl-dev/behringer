## Goal

Write `src/test_toast_logic.c` using TDD (red→green, one test at a time). Tests verify the five public functions from `toast_logic.h` through their interfaces only — no access to internal state. Follow the vertical-slice approach: write one test, make it pass, repeat.

## Test file pattern

Follow `src/test_x32tap.c` exactly:
- Standalone `main()` binary, no test framework
- `ok(name)` / `fail(name, reason)` helpers + `ASSERT_INT_EQ` / `ASSERT_FLOAT_EQ` macros
- Exits with `failed ? 1 : 0`
- Final line: `printf("\n%d passed, %d failed\n", passed, failed)`

## Behaviors to test (implement in this order — tracer bullet first)

### 1. `db_to_geq_float` — tracer bullet (simplest pure math, proves the link works)

```
db_to_geq_float: 0 dB = 0.5
db_to_geq_float: -15 dB = 0.0
db_to_geq_float: +15 dB = 1.0
db_to_geq_float: -6 dB = 0.3
db_to_geq_float: -9 dB = 0.2
```

### 2. `bin_to_geq_par` — calibration anchor (wrong answer → wrong notch frequency)

```
bin_to_geq_par: bin 56 = par 18  (1 kHz — pistonphone calibration point)
bin_to_geq_par: bin 0  = par 1   (20 Hz — lowest band)
bin_to_geq_par: bin 99 = par 31  (20 kHz — highest band)
bin_to_geq_par: bin 23 = par 8   (100 Hz)
bin_to_geq_par: bin 50 = par 17  (midpoint between 630 Hz [49] and 800 Hz [53], closer to 630)
```

Verify `TOAST_GEQ_BIN[17]` == 56 (confirms the lookup table is exported correctly).

### 3. `parse_meters4_blob` — blob parsing

Build a synthetic blob in the test:

```c
/* Synthetic /meters/4 blob: 4-byte BE size (208) + 4-byte LE count (100) + 200 bytes samples */
uint8_t blob[208];
memset(blob, 0, sizeof(blob));
/* BE size = 208 */
blob[0] = 0; blob[1] = 0; blob[2] = 0; blob[3] = 208;
/* LE count = 100 */
blob[4] = 100; blob[5] = 0; blob[6] = 0; blob[7] = 0;
/* Set bin 56 to int16 value -5120 = -20 dBFS (0xEC00 LE: blob[120]=0x00, blob[121]=0xEC) */
int16_t val = -5120;  /* -20 * 256 */
memcpy(blob + 8 + 56*2, &val, 2);
```

```
parse_meters4_blob: returns 0 for valid 100-value blob
parse_meters4_blob: bin 56 decoded as -20.0 dBFS
parse_meters4_blob: all-zero bins decode as 0.0 dBFS
parse_meters4_blob: returns -1 for blob shorter than 8 bytes
parse_meters4_blob: returns -1 when n_vals != 100
```

For the "n_vals != 100" test, set `blob[4] = 44` (mimics /meters/5 which has 44 values).

### 4. `detect_peak` — spike detection

```c
float bins[100]     = {0};
float baseline[100] = {0};
int   peak_bin      = -1;

/* no spike: all bins at baseline */
detect_peak: returns 0 when no bin exceeds threshold

/* single spike: bins[56] = baseline[56] + 25 dB (threshold = 20) */
detect_peak: returns 1 when bin 56 is 25 dB above baseline
detect_peak: peak_bin is 56 when bin 56 is the only spike

/* two spikes: bins[23] +25 dB, bins[56] +30 dB — picks the higher one */
detect_peak: peak_bin is 56 (higher level wins over 23)

/* spike exactly at threshold: should NOT trigger */
detect_peak: returns 0 when excess == threshold (strict greater-than)
```

### 5. `update_baseline` — exponential smoothing

```
update_baseline: baseline converges toward signal over many iterations
update_baseline: alpha=0 leaves baseline unchanged
update_baseline: alpha=1 sets baseline equal to bins immediately
update_baseline: only n elements are updated (element n is not touched)
```

For convergence: start baseline at 0.0, bins at 100.0, alpha=0.5. After 1 call, baseline[0] should be 50.0.
