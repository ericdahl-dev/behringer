## Goal

Implement `RingoutSession.swift` — the object that runs one complete proactive
ring-out pass on a monitor bus. It wires together:

- `AudioCaptureEngine` (IOS-004) + `FFTEngine` (IOS-003) — phone mic as acoustic sensor
- `RingoutController` (IOS-008) — decision engine
- `MixerConnection` (IOS-009) — OSC transport

It owns the fader capture/restore invariant (the bus fader is always returned to its
original value on stop or abort, matching the CLI's `ringout_panic()`), publishes
live state to SwiftUI via `@Published`, and optionally supports supervised mode
(pausing before each gain raise for operator confirmation).

## File

`ios/ToastSaver/RingoutSession.swift`

## Public interface

```swift
import Combine
import ToastSaverCore

@MainActor
final class RingoutSession: ObservableObject {

    // MARK: - Published state (SwiftUI binds to these)

    @Published private(set) var phase: Phase = .idle
    @Published private(set) var currentGainDB: Float = 0
    @Published private(set) var notchCount: Int = 0
    @Published private(set) var activeNotches: [Bool] = Array(repeating: false, count: 31)
    @Published private(set) var logLines: [String] = []

    enum Phase: Equatable {
        case idle
        case calibrating(framesCollected: Int, framesNeeded: Int)
        case analyzing
        case settling
        case waitingForConfirm(nextGainDB: Float)   // supervised mode only
        case done(reason: RingoutDoneReason, marginDB: Float)
        case aborted(reason: String)
    }

    // MARK: - Configuration

    struct Config {
        var mixerModel: MixerModel
        var mixerHost: String
        var bus: Int                // monitor bus 1–N (max per model)
        var fxSlot: Int             // TEQ FX slot
        var rtaChannel: Int         // RTA source channel (set on mixer)
        var ringoutConfig: RingoutConfig
        var supervised: Bool        // pause before each gain raise
        var calibrationFrames: Int  // default 40 (~2 s at 20 Hz)
    }

    // MARK: - Init

    init(connection: MixerConnection, audio: AudioCaptureEngine, fft: FFTEngine)

    // MARK: - Control

    /// Begin a ring-out run with the given config.
    /// Captures the current fader, calibrates baseline, then starts the ramp loop.
    /// Returns immediately; observe `phase` for progress.
    func start(config: Config)

    /// Abort the current run. Restores the fader and reverts notches.
    func stop()

    /// In supervised mode: confirm the pending gain raise and apply it.
    /// No-op if not in `.waitingForConfirm`.
    func confirmRaise()
}
```

## Implementation

### Fader capture and restore invariant

Mirror `ringout_panic()` from the CLI exactly:

```swift
private var capturedFader: Float? = nil

private func captureFader(bus: Int) async {
    capturedFader = await connection.readFader(bus: bus)
    guard capturedFader != nil else {
        await MainActor.run { phase = .aborted(reason: "No reply reading bus \(bus) fader — refusing to drive") }
        return
    }
}

private func restoreFader(bus: Int) {
    guard let fader = capturedFader else { return }
    connection.writeFader(bus: bus, value: fader)
    log("[ring-out] fader restored to \(fader)")
}
```

If `captureFader` fails (no reply), abort before touching anything. The fader is
always restored on `stop()` and at the end of `start()` (whether completed or not).

### Calibration phase

Collect `config.calibrationFrames` FFT frames to build the initial baseline before
starting the ramp. During calibration, hold gain at `startGainDB` (the captured
original).

```swift
private func calibrate(config: Config) async -> [Float]? {
    var accum = [Float](repeating: 0, count: 31)
    var count = 0
    phase = .calibrating(framesCollected: 0, framesNeeded: config.calibrationFrames)

    for await geqLevels in audioFrames {   // async stream from AudioCaptureEngine+FFTEngine
        for i in 0..<31 { accum[i] += geqLevels[i] }
        count += 1
        phase = .calibrating(framesCollected: count, framesNeeded: config.calibrationFrames)
        if count >= config.calibrationFrames { break }
    }
    return count > 0 ? accum.map { $0 / Float(count) } : nil
}
```

### Main ramp loop

After calibration, run `RingoutController.step()` on each incoming FFT frame:

```swift
private func runLoop(config: Config, initialBaseline: [Float]) async {
    var baseline = initialBaseline
    let controller = RingoutController(config: config.ringoutConfig)
    var notchStates = [Bool](repeating: false, count: 31)
    var tracker = BaselineTracker(baseline: baseline)

    for await geqLevels in audioFrames {
        tracker.update(with: geqLevels, alpha: 0.005)
        baseline = tracker.baseline

        let action = controller.step(geqLevels: geqLevels, baseline: baseline)

        switch action {
        case .hold:
            break

        case .raiseGain(let gainDB):
            if config.supervised {
                phase = .waitingForConfirm(nextGainDB: gainDB)
                // suspend until confirmRaise() or stop()
                await waitForConfirmation(gainDB: gainDB, config: config)
            } else {
                connection.writeFader(bus: config.bus,
                                      value: faderDBToFloat(gainDB))
                currentGainDB = gainDB
                log("[ring-out] raise → \(gainDB, format: .fixed(1)) dB")
            }
            phase = .settling

        case .backOff(let gainDB):
            connection.writeFader(bus: config.bus, value: faderDBToFloat(gainDB))
            currentGainDB = gainDB
            log("[ring-out] back off → \(gainDB, format: .fixed(1)) dB")

        case .placeNotch(let par, let cutDB):
            connection.sendNotch(slot: config.fxSlot, par: par, dB: cutDB)
            notchStates[par - 1] = true
            notchCount = controller.notchCount
            activeNotches = notchStates
            log("[ring-out] notch par \(par) at \(gainDB, format: .fixed(1)) dB")

        case .done(let reason, let margin):
            log("[ring-out] done: \(reason) margin \(margin, format: .fixed(1)) dB")
            phase = .done(reason: reason, marginDB: margin)
            restoreFader(bus: config.bus)
            return   // leave notches in place — ring-out result

        case .abort(let reason):
            log("[ring-out] abort: \(reason)")
            phase = .aborted(reason: "\(reason)")
            revertNotches(slot: config.fxSlot, notchStates: notchStates)
            restoreFader(bus: config.bus)
            return
        }

        phase = controller.currentGainDB >= config.ringoutConfig.ceilingDB - 0.01
            ? .settling : .analyzing
        currentGainDB = controller.currentGainDB
    }
}
```

### Revert notches on abort

Only revert if the run was aborted or interrupted — match CLI behaviour where
notches are left in place on clean completion:

```swift
private func revertNotches(slot: Int, notchStates: [Bool]) {
    for (i, active) in notchStates.enumerated() where active {
        connection.sendFlat(slot: slot, par: i + 1)
    }
    activeNotches = [Bool](repeating: false, count: 31)
    log("[ring-out] notches reverted")
}
```

### Audio frame stream

`AudioCaptureEngine` (IOS-004) calls the FFT callback on a background queue.
Wrap it in an `AsyncStream` so the ramp loop can `for await` over frames:

```swift
private var audioFrames: AsyncStream<[Float]> {
    AsyncStream { continuation in
        audio.onFrame = { [weak fft] samples in
            guard let fft else { return }
            let bins = fft.process(samples)
            let geqLevels = fft.geqBins.map { bins[$0] }
            continuation.yield(geqLevels)
        }
    }
}
```

### Supervised mode

When `config.supervised == true` and the controller returns `.raiseGain`, the
session enters `.waitingForConfirm`. It suspends the ramp loop using a
`CheckedContinuation` stored in `pendingConfirmation`. `confirmRaise()` resumes
it; `stop()` cancels it (which triggers the abort path).

### Logging

```swift
private func log(_ message: String) {
    let line = "[\(timestamp())] \(message)"
    logLines.append(line)
    if logLines.count > 200 { logLines.removeFirst() }
}
```

## Acceptance Criteria

- [ ] `start(config:)` on a reachable XR18 captures the fader before raising gain.
- [ ] If `readFader` returns nil, `phase` becomes `.aborted(...)` immediately and
  no fader or notch commands are sent.
- [ ] After a clean `.done`, notches remain on the mixer; the fader is restored.
- [ ] After `stop()` or an `.abort`, notches are reverted; the fader is restored.
- [ ] In supervised mode, gain is not raised until `confirmRaise()` is called.
- [ ] `stop()` during supervised wait aborts cleanly (reverts, restores).
- [ ] `logLines` receives a human-readable entry for: calibration done, each raise,
  each back-off, each notch, completion/abort.
- [ ] `currentGainDB` never exceeds `config.ringoutConfig.ceilingDB`.
- [ ] `activeNotches[i]` is true iff GEQ par `i+1` has a notch currently in place.

## Notes

- `faderDBToFloat` is a direct Swift port of `fader_db_to_float()` from
  `cli/toast_logic.c` (piecewise linear). Add it as a private helper or to
  `ToastSaverCore` (preferred — it's model-agnostic and testable on Linux).
- `RingoutSession` is the only place that calls `connection.writeFader` or
  `connection.readFader`. `NotchController` from IOS-005 handles the reactive
  (post-ring-out) notch state machine; it is a separate object, not part of this task.
- Keep this class focused on the ring-out workflow. Reactive mode live protection
  is a separate session type (future task).
