## Goal

Implement `handle_meters4()` in `src/XAir_ToastSaver.c`: parse the `/meters/4` blob into 100 float dBFS values, maintain a per-bin rolling noise floor baseline, and expose the calibrated bin values to the detection stage (T-015).

## Context

The XR18 sends `/meters/4` blobs at ~20 Hz (every 50 ms) once subscribed. Each blob contains a 100-bin RTA spectrum covering 20 Hz–~21.6 kHz. All OSC meter values are signed 16-bit integers; divide by 256.0 to get dBFS. The blob format has two headers before the samples:

```
bytes [0–3]   big-endian uint32   total blob byte count  (= 208)
bytes [4–7]   little-endian uint32  number of int16 values (= 100)
bytes [8–207] 100 × little-endian int16  sample values
```

Bins are logarithmically spaced. The empirically calibrated formula (pistonphone 1 kHz @ 94 dB SPL → peak at bin [56]):

```
f(n) = 20 × 10^(n / 100 × 3.0339)   Hz for bin n
n(f) = round(100 / 3.0339 × log10(f / 20))  bin for frequency f
```

Full calibrated bin→Hz table is in `docs/xr18-meters-osc.md`.

The preamp electronic noise floor is typically −80 to −97 dBFS per bin when the channel is muted. Feedback spikes appear 30–50 dB above that floor.

## Acceptance Criteria

- [ ] `handle_meters4()` parses the blob header (big-endian size, little-endian count) and rejects packets where count ≠ 100.
- [ ] All 100 int16 values extracted and divided by 256.0 to produce `float bins[100]` in dBFS.
- [ ] Baseline calibration: during the first `BASELINE_FRAMES` (default: 40, = ~2 seconds at 20 Hz), accumulate a running average per bin into `float baseline[100]`. After calibration is complete, set a `bool baseline_ready` flag and print a one-line status: `baseline established: avg noise floor = {mean_of_baseline} dBFS`.
- [ ] After baseline, each incoming frame updates the baseline slowly using exponential smoothing: `baseline[i] = 0.995 * baseline[i] + 0.005 * bins[i]`. This adapts to room changes over time without chasing transients.
- [ ] Expose `float bins[100]` and `float baseline[100]` in `AppState` so the detection stage (T-015) can read them directly.
- [ ] In verbose mode (`-v`), print the peak bin index and its dBFS value each frame.

## Blob Parsing — C Reference

```c
static void handle_meters4(const uint8_t *blob, int blen, AppState *s) {
    if (blen < 8) return;

    /* header */
    uint32_t byte_count;
    memcpy(&byte_count, blob, 4);
    byte_count = ntohl(byte_count);           /* big-endian */

    uint32_t n_vals;
    memcpy(&n_vals, blob + 4, 4);
    /* n_vals is little-endian; on x86/ARM no swap needed, but be explicit: */
    n_vals = (uint32_t)blob[4] | ((uint32_t)blob[5] << 8)
           | ((uint32_t)blob[6] << 16) | ((uint32_t)blob[7] << 24);

    if (n_vals != 100) return;
    if (blen < 8 + (int)(n_vals * 2)) return;

    for (int i = 0; i < 100; i++) {
        int16_t raw;
        memcpy(&raw, blob + 8 + i * 2, 2);   /* LE signed — no swap on LE host */
        s->bins[i] = (float)raw / 256.0f;
    }
    /* baseline and detection follow here */
}
```

## Notes

- The incoming OSC packet from `recvfrom()` is a full OSC message. The blob starts after the OSC address (`/meters/4`), type tag (`,b`), and 4-byte big-endian blob size field. You must skip the OSC framing before calling `handle_meters4()`. Check the address string first, then advance the pointer past the OSC headers (address padded to 4-byte boundary, type tag padded to 4-byte boundary, 4-byte blob length) to reach the raw blob bytes. Pass the blob pointer and remaining byte count to `handle_meters4()`.
- Do not use `Xcparse()` for binary meter blobs — parse directly.
- `BASELINE_FRAMES` should be a `#define` at the top of the file so it can be tuned without searching.
